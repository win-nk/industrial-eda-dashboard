ทำแล้วได้อะไร

ได้ portfolio piece แรกที่ใช้สมัครงานได้ทันที · ฝึกทักษะ Pandas + Matplotlib + Seaborn · ได้ผลลัพธ์ที่นำไปต่อใน Project #2 ได้โดยตรง · เรียนรู้การเชื่อม data กับ business value

ผลลัพธ์ที่คาดหวัง (และได้แล้ว)

Failure rate: 3.39% · Top mode: HDF (33.9%) · โซนอันตราย: Torque > 60 + RPM < 1400 ที่มี failure rate 40.1% (12× baseline) — ตัวเลขนี้ใช้เป็น headline insight ในการสัมภาษณ์

AI4I 2020

ต้องทำอะไร

ใช้ข้อมูลเดิมจาก Project #1 มาสร้าง classification model (Random Forest หรือ XGBoost) เพื่อทำนายว่าเครื่องจักรจะเสียเมื่อไหร่ · ทำ feature engineering เพิ่ม · evaluate ด้วย Precision/Recall/F1 · สร้าง dashboard แสดงผลทำนาย · คำนวณ ROI เป็นบาท

ทำแล้วได้อะไร

Main selling point ของ portfolio — HR สาย industrial ในไทยจะประทับใจมาก เพราะแสดงว่าทำได้ทั้ง analysis และ ML · เป็นจุดที่ทำให้คุณแตกต่างจาก data analyst ทั่วไป ที่ทำแค่ EDA + dashboard

ผลลัพธ์ที่คาดหวัง

Recall ≥ 80% ของ machine_failure (จับการเสียได้ก่อน 80%) · F1 ≥ 0.65 · ROI calculation: "ป้องกันการเสียได้ 50% = ประหยัด THB 3M/เดือน/โรงงาน" · มี dashboard แสดง predictions แบบ real-time

ขั้นตอนการทำ — 7 ขั้นใน 3-4 สัปดาห์

1
Feature Engineering (สัปดาห์ที่ 1)
สร้าง features ใหม่: temp_gap, power = torque × rpm, tool_wear_rate, rolling_avg_torque (window 5/10/20) · สร้าง in_danger_zone binary flag
2
Train/Test Split (สัปดาห์ที่ 1)
ใช้ train_test_split + stratify เพื่อรักษาสัดส่วน failure ใน train และ test · split 80/20 · ตั้ง random_state ให้ reproducible
3
Train Baseline Models (สัปดาห์ที่ 2)
Train 3 models เปรียบเทียบ: Logistic Regression (baseline) · Random Forest · XGBoost · ใช้ class_weight='balanced' แก้ปัญหา class imbalance (failure rate แค่ 3.39%)
4
Evaluate Models (สัปดาห์ที่ 2)
Metrics: classification_report (Precision/Recall/F1) + confusion_matrix + ROC-AUC · เน้น Recall มากกว่า Accuracy (เพราะ false negative = เครื่องเสียจริงแต่ไม่เตือน คือ cost สูงสุด)
5
Hyperparameter Tuning (สัปดาห์ที่ 3)
ใช้ GridSearchCV หรือ RandomizedSearchCV หา hyperparameter ที่ดีที่สุด · ทำ k-fold cross-validation (5-fold) · save model ที่ดีสุดเป็น .pkl
6
Feature Importance + SHAP (สัปดาห์ที่ 3)
Plot feature importance ของ XGBoost · ใช้ SHAP เพื่ออธิบายแต่ละ prediction · พิสูจน์ว่า model "เข้าใจ" ฟิสิกส์เครื่องจักร (Torque, Tool wear ควรเป็น top features)
7
Dashboard + ROI (สัปดาห์ที่ 4)
สร้าง Looker dashboard เพิ่มจาก Project #1: predictions · confidence scores · maintenance alerts · ROI calculator → สรุปเป็นบาท: "Model นี้ลด downtime X% = Y THB/เดือน"

Key Metrics ที่ต้องนำเสนอใน README

Metricเป้าหมายความหมายทางธุรกิจ
Recall≥ 0.80จับเครื่องที่จะเสียได้ 80% (ไม่พลาด)
Precision≥ 0.50เมื่อเตือนแล้ว ถูก 50% ขึ้นไป
F1 Score≥ 0.65สมดุลระหว่าง Precision และ Recall
ROC-AUC≥ 0.85โมเดลแยกกลุ่มได้ดีกว่าสุ่ม
Cost saving≥ 1M THB/เดือนมูลค่าทางธุรกิจ — ที่ HR สนใจที่สุด
⚠️ ข้อระวัง: อย่ายึด Accuracy เด็ดขาด — ถ้าโมเดลทาย "ไม่เสีย" ทุกครั้งจะได้ Accuracy 96.61% ทันที (เพราะ failure แค่ 3.39%) แต่ Recall = 0 = เลือกใช้งานจริงไม่ได้ ใน interview ต้องอธิบายเรื่องนี้ให้ได้

ต้องทำอะไร

โหลด defect detection dataset (NEU Metal Surface Defects หรือ MVTec AD) · train CNN model เพื่อจำแนก "ดี" vs "เสีย" · แสดงผล Accuracy/Precision/Recall บน dashboard · อัด video demo โชว์ model ตรวจจับ defect แบบ real-time · ใส่ link video ใน GitHub README

ทำแล้วได้อะไร

The Showstopper — Computer Vision ใน data analyst portfolioหาได้ยากมากในไทย · ทำให้ HR จดจำคุณ · เปิดประตูสู่บริษัทระดับสูงเช่น KBTG, SCB Tech X, Bosch · ใช้สมัคร AI engineer ได้ด้วย ไม่จำกัดแค่ analyst

ผลลัพธ์ที่คาดหวัง

Accuracy ≥ 90% ใน defect classification · Demo video 30-60 วินาทีโชว์ model วิเคราะห์ภาพแบบ real-time · ขั้นสูง: deploy เป็น Streamlit app ที่ upload รูปแล้วได้ผลทันที

ขั้นตอนการทำ — 8 ขั้นใน 4-5 สัปดาห์

1
Setup + Download Dataset (สัปดาห์ที่ 1)
Download NEU dataset (kaggle.com/datasets/fantacher/neu-metal-surface-defects-data) · 1,800 ภาพ · 6 categories · Setup environment ที่มี TensorFlow + OpenCV + Pillow
2
EDA Image Data (สัปดาห์ที่ 1)
ดูตัวอย่างภาพแต่ละ class · plot histogram ของ pixel intensities · check class balance · split train/val/test (70/15/15) · resize ทุกภาพให้เป็น 224×224 (มาตรฐาน CNN input)
3
Data Augmentation (สัปดาห์ที่ 2)
ใช้ ImageDataGenerator ของ Keras: rotation, flip, zoom, brightness · เพิ่มจำนวน effective training samples · ป้องกัน overfitting
4
Train CNN (สัปดาห์ที่ 2-3)
เริ่มจาก simple CNN (3-4 conv layers + 2 dense) เป็น baseline → upgrade เป็น Transfer Learning ด้วย MobileNetV2 หรือ ResNet50 (pre-trained บน ImageNet)
5
Evaluate (สัปดาห์ที่ 3)
Confusion matrix · per-class Precision/Recall · plot training curves (loss + accuracy) · พิสูจน์ไม่มี overfitting · ทดสอบบน test set ที่ไม่เคยเห็น
6
Build Dashboard (สัปดาห์ที่ 4)
สร้าง Streamlit app: upload image → preprocess → predict → แสดงผล + confidence + heatmap (Grad-CAM โชว์ว่า model มองที่ไหน) · deploy บน Streamlit Cloud (ฟรี)
7
Record Demo Video (สัปดาห์ที่ 4)
อัดวีดีโอ 30-60 วินาที: เปิด app → upload ภาพชิ้นงานเสีย → เห็น model จำแนกถูก → Grad-CAM โชว์จุดเสีย · upload ขึ้น YouTube · ใส่ link ใน README
8
Polish + Apply (สัปดาห์ที่ 5)
README ละเอียด: dataset · model architecture · results · video link · live demo URL · update LinkedIn · apply ไปบริษัทเป้าหมาย — portfolio ครบ 3 ขา พร้อม
