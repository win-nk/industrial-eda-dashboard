เช็คคุณภาพข้อมูล 2 อย่างหลัก: missing values กับ duplicates — ถ้ามีต้องตัดสินใจก่อนวิเคราะห์
ใช้ต่อ: เช็คทุกครั้งหลังโหลด · ตัดสินใจ: ลบ (dropna) / เติม (fillna) / ปล่อยไว้

หมวด 4 · Filtering & Selection

เลือกและกรองข้อมูล

df[col] / df[[col1, col2]]★★★
df['Torque [Nm]'] # เลือก 1 column → Series df[['Torque [Nm]', 'Type']] # เลือกหลาย column → DataFrame df[SENSOR_COLS] # list ของชื่อ → DataFrame
เลือก column — ใช้ list of names ถ้าจะเลือกหลาย column ในครั้งเดียว สังเกต [[ สอง bracket
ใช้ต่อ: หัวใจของการทำงานกับ pandas · เก็บ list ของ column ไว้เป็น constant (เช่น SENSOR_COLS) แล้ว reuse
df[df[col] == value]★★★
# Boolean indexing healthy = df[df['Machine failure'] == 0] failed = df[df['Machine failure'] == 1] # หลายเงื่อนไข — ต้องใช้ () ครอบและ & | risky = df[(df['Torque [Nm]'] > 60) & (df['Rotational speed [rpm]'] < 1400)]
กรองแถวด้วยเงื่อนไข — สร้าง boolean Series แล้วใส่ใน [] · หลายเงื่อนไขใช้ & (AND) และ | (OR) ห้าม and / or
ใช้ต่อ: filter ทุกครั้งที่อยากดู subset · ใช้สร้าง training/test split ก่อน scikit-learn
df.loc[mask, col]★★
# เลือก row และ column พร้อมกัน df.loc[df['Machine failure'] == 1, 'n_failure_modes'] # 1 col df.loc[df['Type'] == 'L', ['Torque [Nm]', 'HDF']] # หลาย col
เลือกแถวและ column ในคำสั่งเดียว — เร็วกว่า df[df[...]==...][cols] และ idiomatic กว่า
ใช้ต่อ: ใช้แทน chain indexing ทุกครั้ง — ลด SettingWithCopyWarning
df.iloc[]★
df.iloc[0] # แถวแรก (by position) df.iloc[0:5, :3] # 5 แถวแรก, 3 column แรก df.iloc[-1] # แถวสุดท้าย
เลือกด้วย integer position — เหมือน list/numpy slicing ต่างจาก .loc ที่ใช้ label/condition
ใช้ต่อ: เมื่อสนใจตำแหน่งจริงๆ (เช่น แถวสุดท้าย, sample จาก index)
df.query()★
# Alternative ที่อ่านง่าย df.query('`Torque [Nm]` > 60 and `Rotational speed [rpm]` < 1400') df.query('Type == "L"')
กรองด้วย string syntax — อ่านง่ายกว่า boolean indexing ตอนเงื่อนไขเยอะ · column ที่มี space ต้องครอบด้วย backtick
ใช้ต่อ: code review · ตอนแชร์โน้ตบุ๊กให้คนไม่คุ้น pandas อ่านง่ายกว่า boolean indexing

สรุปข้อมูล (groupby, sum, count)

df[col].value_counts()★★★

ใช้ต่อ: ทุก categorical column · ทดสอบ class balance ก่อน train ML
df[col].sum() / .mean()★★★
df['Machine failure'].sum() # รวม (สำหรับ binary = นับจำนวน 1) df['Torque [Nm]'].mean() # ค่าเฉลี่ย df['Torque [Nm]'].std() # ส่วนเบี่ยงเบนมาตรฐาน df[FAILURE_COLS].sum() # sum หลาย column พร้อมกัน → Series
คำสั่งสถิติพื้นฐาน — ใช้ทั้งกับ Series เดี่ยว และ DataFrame หลาย column
ใช้ต่อ: ใช้บ่อยมากในการคำนวณ KPI เช่น failure rate, average sales, total revenue
df.groupby(...).agg(...)★★★
by_type = df.groupby('Type').agg( n=('UDI', 'count'), failures=('Machine failure', 'sum'), ) # Named aggregation: column_name=(source_col, agg_function)
หัวใจของการสรุปแบบกลุ่ม — group by column แล้ว aggregate · ใช้ named aggregation (ดังตัวอย่าง) เพื่อตั้งชื่อ column ใหม่ชัดเจน
ใช้ต่อ: ทุกครั้งที่อยากสรุปข้อมูลแบบ "แต่ละ X เป็นยังไง" · เช่น sales per region, defects per machine, response time per priority
.sort_values()★★
df[FAILURE_COLS].sum().sort_values(ascending=False) # เรียง count จากมากไปน้อย df.sort_values('Torque [Nm]', ascending=False).head(10) # top 10 แถวที่ torque สูงสุด
เรียงข้อมูล — ใช้กับทั้ง Series และ DataFrame · default คือ ascending
ใช้ต่อ: ทุกครั้งที่ต้องการ top N หรือ bottom N · ใช้ก่อน .head()
.sum(axis=1)★★
df['n_failure_modes'] = df[FAILURE_COLS].sum(axis=1) # axis=1 → sum ตามแถว (ไม่ใช่ตาม column) # แต่ละแถวจะได้ค่ารวมของ TWF+HDF+PWF+OSF+RNF

ใช้ต่อ: รวม binary flags หลายตัว · sum ข้าม column ของ feature engineering

คำนวณ correlation ระหว่างทุกคู่ column — ค่าระหว่าง −1 ถึง +1 · ใกล้ 0 = ไม่มีความสัมพันธ์เชิงเส้น

ใช้ต่อ: หา top performer · machine ที่เสียบ่อยสุด · timestamp ที่ peak
